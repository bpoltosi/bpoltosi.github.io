# Portfólio — bpoltosi

Site pessoal e portfólio de desenvolvimento de software, publicado como GitHub Pages.

## Implementação

O repositório contém uma página estática principal em `index.html`, com estrutura, estilos e scripts incorporados no próprio documento. A interface apresenta identidade visual escura, navegação, seções de portfólio e recursos visuais animados.

## Publicação

O repositório segue a convenção `<usuario>.github.io`, permitindo publicação como site de usuário no GitHub Pages.

Acesse: https://bpoltosi.github.io/

## Desenvolvimento

Edite `index.html` e abra o arquivo em um navegador para conferir localmente. Para testar a experiência de publicação, utilize o GitHub Pages nas configurações do repositório.

## Status

Portfólio estático em evolução. O repositório atualmente possui uma página principal; não há backend ou sistema de build separado identificado na estrutura.
